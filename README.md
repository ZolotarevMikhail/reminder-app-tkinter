# Напоминалка (PRJ1)

Учебный проект: desktop-напоминалка на Python (tkinter + SQLite3).

## Файлы

- `prompt.txt` — промпт из урока, по которому сгенерирован проект
- `main.py` — точка входа, запуск приложения
- `database.py` — работа с базой SQLite (класс ReminderDatabase)
- `gui.py` — окно приложения (класс ReminderApp)
- `notifications.py` — фоновая проверка времени и очередь уведомлений

## Как запустить

```bash
cd PRJ1
python3 main.py     # на Windows: python main.py
```

## Что умеет

- Добавлять напоминание (заголовок, описание, дата/время)
- Быстрые кнопки «Через 1/5/15 мин», «Через 1 час»
- Уведомление — всплывающее окно поверх всех окон, работает при свёрнутом окне программы
- Отмечать «Готово» / «Отменено», удалять
- Просроченные автоматически получают статус «Просрочено»
- Фильтр списка по статусу, цветная подсветка строк
